Why This Matters

Ethiopia and Eritrea have a rich manuscript heritage. HMML’s Ethiopian collections document manuscripts in Geʼez and other languages, but the collections do not authenticate this museum’s substitution model. No shelfmark, historical key, or deciphered specimen has been identified for this model. The widget is an educational construction.

Historical Context

Geʼez is a language; Ethiopic is the script also adapted for Amharic and other languages. Its signs organize consonant and vowel information. Script inventories differ by language, so an Amharic-style count of 33 base forms must not be presented as the standard Geʼez inventory. An unfamiliar script is not, by itself, encryption.

How the Teaching Model Works

The demonstration permutes the 26 Latin letters A–Z using a keyword-seeded shuffle. It uppercases the input and discards characters outside A–Z. It neither accepts an Ethiopic alphabet nor reconstructs a manuscript cipher. The exercise illustrates repeated-letter patterns in a fixed substitution; it does not model Geʼez spelling or syllables.

Security Analysis
Letter-frequency analysis
Model limitation: no measured historical attack complexity

A fixed substitution preserves repeat patterns. An analyst needs language-appropriate evidence, enough ciphertext, and the correct model to exploit them. A larger symbol inventory can make short samples harder to analyze, but neither unfamiliarity nor alphabet size proves security. No historical adversary or operational security claim is established for this exercise.
