# Cipher Museum v1.0.0 — Initial software archive

Cipher Museum is a static, browser-based digital museum, cipher playground,
and codebreaking classroom spanning more than 3,900 years of cryptography. This
is the first citable software release of the museum itself.

[![Cipher Museum software v1.0.0 DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23298941.svg)](https://doi.org/10.5281/zenodo.23298941)

- Software version DOI: [10.5281/zenodo.23298941](https://doi.org/10.5281/zenodo.23298941)
- Software concept DOI: [10.5281/zenodo.23298940](https://doi.org/10.5281/zenodo.23298940)

## Highlights

- 167 exhibits: 147 cipher and history exhibits across 13 halls, a 17-exhibit
  Hall of Foundations mathematics annex, and 3 modern protocol/construction
  exhibits.
- 88 registered cipher engines and 146 interactive exhibits, implemented in
  browser-native HTML, CSS, and JavaScript without an application framework.
- Historical timelines, guided tours, comparison tools, challenges, a
  glossary, searchable exhibit metadata, and trust/source labels.
- Reproducible engine verification, known-answer tests, property testing,
  corpus replay, rendered-demo tests, link checks, HTML lint, accessibility
  checks, responsive-layout checks, and service-worker freshness guards.
- Integration with the separately archived Cipher Corpus v0.6: 100,326
  canonical records across 85 cipher-type labels.

## Running the museum

The site is static and does not require a production build:

```bash
git clone https://github.com/systemslibrarian/cipher-museum.git
cd cipher-museum
python3 -m http.server 8000
```

Open <http://localhost:8000>. Install Git LFS before cloning, or run
`git lfs pull`, if local copies of the large corpus JSON/JSONL files are needed.

## Scope and known limitations

- Cipher implementations and exercises are educational demonstrations, not
  production cryptographic libraries. Do not use them to protect sensitive
  information.
- Historical procedures are implemented to the documented conventions and
  source evidence available to the project. Exhibits identify simulations,
  reconstructions, variants, and unresolved historical uncertainty through
  trust and source notes.
- Cipher Corpus is a related dataset, not the software release. GitHub-generated
  source archives currently contain Git LFS pointers for `all.json` and
  `all.jsonl`, not their dataset payloads.
- The live museum is continuously deployed and may later differ from this
  immutable software release.
